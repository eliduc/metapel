# Выплаты метапелю

Веб-приложение напоминаний о выплатах обслуживающему работнику (метапелю) в Израиле:
зарплата + шабат, карманные (дмей кис), мед. страховка, Битуах Леуми, пикадон,
дмей хавраа, виза, тагид, разрешение.

**Приложение:** https://eliduc.github.io/metapel/

- Считает суммы и показывает, как они посчитаны (по памятке агентства и законам Израиля).
- Напоминает заранее (срок настраивается по каждому типу) и каждый день после срока, пока не нажата «✓ Я заплатил».
- Способ оплаты: перевод или наличные. Для наличных метапель расписывается пальцем — расписка хранится вместе с платежом.
- Дополнительные платежи: 🎁 подарок (расписка по желанию) и 🧾 под отчёт — с учётом возвратов (чеки/сдача) и балансом «на руках».
- Архив расписок (опционально): подписанные расписки сохраняются в приватный репозиторий GitHub через Contents API (токен вводится в настройках).
- Интерфейс рассчитан на пожилого пользователя: крупный шрифт, большие кнопки, статусы словами и цветом.
- Все параметры — в настройках (⚙, пароль по умолчанию `1234`).
- Данные хранятся локально в браузере (localStorage), сервера нет.

## Как пользоваться на iPad / телефоне

Открыть ссылку в Safari/Chrome → «Поделиться» → «На экран “Домой”» — появится иконка ₪.

## Разработка

Статические файлы, без сборки. Расчётный движок — [js/calc.js](js/calc.js) (без DOM, переносится в будущую Android-версию).
Тесты движка: открыть [tests/test.html](tests/test.html). Симуляция даты: `index.html?today=2026-12-09`.
